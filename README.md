# MV Grid Fault Risk Scoring Platform

Production-first, end-to-end ML system for predicting medium-voltage grid fault risk and prioritising preventive interventions.

**Keywords:** scalable ML pipelines, CI/CD for model deployment, inference scaling, feature engineering, model monitoring, automated retraining, FastAPI, Docker, MLflow.

## What this repo contains
- Data pipeline (ingest → features → training table)
- Model training with MLflow tracking
- FastAPI model serving
- Streamlit demo (interactive risk scoring)

Work in progress — building the full-stack MVP.
